PRIVACY POLICY

How this website handles technical data

Last updated: November 8, 2026 · Version 2.0

This page explains what technical information クルシーP may collect, why it is used, and how you can opt out of analytics.

Analytics is enabled only with your consent. If you choose “Continue without analytics”, the website will not send events to Kuru Telemetry. Core website features remain available.

1. Data controller

Website operator: the owner and administrator of クルシーP (kuru-kuru.ru). For questions about technical data processing, contact us via Telegram.

2. Information collected

After you select “Allow analytics”, your browser may send:

  • a random WBUID generated by the browser and used for analytics on this website only;
  • device type, interface language, screen width and height, pixel ratio, and color depth;
  • browser family and major version, and operating system family;
  • WebGL 1 or WebGL 2 availability, maximum texture size, and number of supported extensions;
  • logical processor count and approximate device memory, if exposed by the browser;
  • connection type and data-saving mode, if provided by the browser;
  • country and region code from Cloudflare network metadata, if available;
  • autonomous system number (ASN) and Cloudflare data-centre code, if available. These details are used for general network and infrastructure diagnostics;
  • page and section views, page-load time, and JavaScript error messages.

3. IP addresses and device identification

An IP address is technically processed by the network infrastructure and CDN while a request is transmitted. Kuru Telemetry does not store full IP addresses in its analytics database. Country and region code supplied by Cloudflare may be used for statistics.

The website does not request WebGL renderer/vendor strings, canvas fingerprints, audio fingerprints, font lists, or other parameters to uniquely identify a device. WBUID is a random identifier local to this website, not a cross-site identifier.

4. Purposes of processing

  • counting visits and section views;
  • understanding browser and device distribution to check compatibility;
  • diagnosing page-load performance and technical errors;
  • protecting the analytics API from excessive requests;
  • counting analytics opt-ins and opt-outs in aggregate, without linking a choice to a WBUID.

The data is not intended for advertising profiles and is not used to display personalised ads.

5. Retention and security

Events and visitor records are automatically deleted after 90 days. Access to the detailed analytics dashboard is protected by administrator authentication. A per-WBUID event limit helps prevent excessive requests.

6. Consent, opt-out, and withdrawal

Your choice is stored in your browser’s local storage. You can opt out when the notice appears. If you have already opted in, use the button below on the same device and in the same browser. The website will request deletion of events and the visitor record associated with the current WBUID, then remove the local identifier.

7. Third-party infrastructure

This website uses Cloudflare for content delivery, DNS, and API operations. Cloudflare may process technical network data as part of providing its services. See: Cloudflare Privacy Policy.

8. Policy changes

If the analytics data collected changes significantly, the consent version will be updated and the website will ask for consent again. The current version is always available at kuru-kuru.ru/privacy.html.
